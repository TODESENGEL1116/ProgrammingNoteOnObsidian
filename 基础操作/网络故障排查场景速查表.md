#### 连不上网

| 排查步骤    | Windows                  | Linux/macOS         |
| ------- | ------------------------ | ------------------- |
| 检查网卡状态  | `ipconfig /all`          | `ip addr show`      |
| 测试内网连通  | `ping 网关IP`              | `ping 网关IP`         |
| 测试外网连通  | `ping 8.8.8.8`           | `ping 8.8.8.8`      |
| 检查DNS解析 | `nslookup www.baidu.com` | `dig www.baidu.com` |
| 查看路由表   | `route print`            | `ip route show`     |
| 检查ARP表  | `arp -a`                 | `ip neigh show`     |

#### 端口不通

|排查步骤|Windows|Linux/macOS|
|---|---|---|
|测试端口连通|`Test-NetConnection -ComputerName 目标 -Port 端口`|`nc -zv 目标 端口`|
|查看本机监听端口|`netstat -ano \| findstr 端口号`|`ss -tunlp \| grep 端口号`|
|查看占用进程|`tasklist /FI "PID eq 进程号"`|`lsof -i :端口号`|
|检查防火墙规则|`netsh advfirewall firewall show rule name=all`|`iptables -L -n` / `ufw status`|
|跟踪路径|`tracert 目标IP`|`traceroute 目标IP`|

#### DNS解析异常

|排查步骤|命令|
|---|---|
|查看当前DNS配置|`ipconfig /all`（Win）/ `cat /etc/resolv.conf`（Linux）|
|用默认DNS查询|`nslookup 域名`|
|用公共DNS查询|`nslookup 域名 8.8.8.8`|
|追踪解析链|`dig +trace 域名`|
|清除DNS缓存|`ipconfig /flushdns`（Win）/ `systemd-resolve --flush-caches`（Linux）|
|查看DNS缓存|`ipconfig /displaydns`（Win）|
|直接编辑hosts测试|`echo "IP 域名" >> /etc/hosts`|

#### WiFi连接问题

|排查步骤|Windows|Linux/macOS|
|---|---|---|
|查看已保存WiFi|`netsh wlan show profiles`|`nmcli connection show`|
|查看WiFi密码|`netsh wlan show profile "名称" key=clear`|`sudo cat /etc/NetworkManager/system-connections/名称`|
|查看信号强度|`netsh wlan show interfaces`|`iwconfig` / `nmcli dev wifi list`|
|扫描可用WiFi|`netsh wlan show networks`|`nmcli dev wifi list`|
|断开重连|`netsh wlan disconnect` → `netsh wlan connect name="名称"`|`nmcli connection up "名称"`|
|查看无线驱动|`netsh wlan show drivers`|`iw dev wlan0 info`|

#### 网络速度慢

|排查步骤|命令|
|---|---|
|测试延迟和丢包|`ping -t 目标IP`（Win）/ `ping 目标IP`（Linux）|
|查看网卡速率|`netsh interface ipv4 show subinterfaces`（Win）/ `ethtool eth0`（Linux）|
|实时流量监控|任务管理器→性能→以太网（Win）/ `iftop -i eth0`（Linux）|
|按进程查流量|PowerShell: `Get-NetTCPConnection` / `nethogs eth0`（Linux）|
|带宽测试|`iperf3 -s`（服务端）/ `iperf3 -c 服务端IP`（客户端）|
|查看网卡错误统计|`netstat -e`（Win）/ `ip -s link show eth0`（Linux）|
|检查是否有大量重传|`netstat -s` → 关注重传统计|

#### 无法访问特定网站/服务

|排查步骤|命令|
|---|---|
|确认DNS能解析|`nslookup 目标域名`|
|测试HTTP连通|`curl -I http://目标域名` / `telnet 目标域名 80`|
|测试HTTPS连通|`curl -I https://目标域名` / `telnet 目标域名 443`|
|绕过代理直连|`curl --noproxy "*" https://目标域名`|
|检查hosts文件|`type C:\Windows\System32\drivers\etc\hosts`（Win）/ `cat /etc/hosts`（Linux）|
|对比不同DNS结果|`nslookup 域名 114.114.114.114` vs `nslookup 域名 8.8.8.8`|

#### 远程桌面连不上

|排查步骤|命令|
|---|---|
|确认目标在线|`ping 目标IP`|
|测试RDP端口|`Test-NetConnection -ComputerName 目标IP -Port 3389`（Win）/ `nc -zv 目标IP 3389`（Linux）|
|检查远程桌面是否开启|`reg query "HKLM\SYSTEM\CurrentControlSet\Control\Terminal Server" /v fDenyTSConnections`|
|开启远程桌面|`reg add "HKLM\SYSTEM\CurrentControlSet\Control\Terminal Server" /v fDenyTSConnections /t REG_DWORD /d 0 /f`|
|检查防火墙放行|`netsh advfirewall firewall show rule name="远程桌面"`|
|放行RDP端口|`netsh advfirewall firewall add rule name="RDP" dir=in action=allow protocol=TCP localport=3389`|

#### IP地址冲突

|排查步骤|命令|
|---|---|
|查看本机IP|`ipconfig`（Win）/ `ip addr`（Linux）|
|检测IP是否被占用|`arping -D -I eth0 目标IP`（Linux）/ `arp -a`（Win，对比MAC）|
|释放并重新获取IP|`ipconfig /release` → `ipconfig /renew`|
|清除ARP缓存|`arp -d *`（Win）/ `ip neigh flush all`（Linux）|
|查看冲突设备MAC|`arp -a 冲突IP` → 对比MAC厂商前缀|

---

> 💡 **排查口诀**：先ping网关看内网，再ping外网看出口，三查DNS四端口，五看路由六防火墙。
