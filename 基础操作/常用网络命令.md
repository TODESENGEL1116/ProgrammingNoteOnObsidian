#### 基础连通性测试

| 命令             | 定义                          | 常用语法                                                               |
| -------------- | --------------------------- | ------------------------------------------------------------------ |
| **ping**       | 通过发送ICMP回显请求包测试与目标主机的连通性和延迟 | `ping <目标IP/域名>`                                                   |
| **ping -t**    | 持续ping目标主机，直到手动停止（Windows）  | `ping -t 8.8.8.8`                                                  |
| **ping -c**    | 指定发送包的数量（Linux/macOS）       | `ping -c 4 8.8.8.8`                                                |
| **ping -l/-s** | 指定数据包大小                     | `ping -l 1024 192.168.1.1`（Win）/ `ping -s 1024 192.168.1.1`（Linux） |
| **ping -f/-M** | 设置不分片标志，用于测试MTU             | `ping -f -l 1472 目标IP`（Win）                                        |

#### 实用组合技巧

|场景|命令组合|
|---|---|
|查找占用某端口的进程|`netstat -ano \| findstr :80`（Win）/ `lsof -i :80`（Linux）|
|根据PID结束进程|`taskkill /PID 进程号 /F`（Win）/ `kill -9 PID`（Linux）|
|批量测试端口连通性|`Test-NetConnection -ComputerName 目标 -Port 端口`（PowerShell）|
|快速检测外网连通性|`ping -c 4 8.8.8.8` 或 `curl -I https://www.baidu.com`|
|查看本机公网IP|`curl ifconfig.me` 或 `curl ip.sb`|
|监控实时流量|`iftop -i eth0` 或 `nethogs`|
|DNS解析全流程排查|`nslookup 域名` → `dig +trace 域名` → `ping 域名`|

---

> 💡 **小贴士**：Windows 10/11 推荐使用 PowerShell 中的 `Test-NetConnection`、`Get-NetAdapter` 等 cmdlet；Linux 推荐使用 `ip` 替代 `ifconfig`，`ss` 替代 `netstat`，这些新工具功能更强、输出更清晰。
