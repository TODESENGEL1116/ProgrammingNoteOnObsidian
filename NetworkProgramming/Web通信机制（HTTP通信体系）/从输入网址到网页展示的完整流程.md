### 各概念的"角色定位"

|步骤|核心概念|一句话职责|类比|
|---|---|---|---|
|第一步|**DNS**|把域名翻译成 IP 地址|查电话簿，找到店铺地址|
|第二步|**TCP**|建立可靠的传输通道|打电话前先拨号、确认对方接听|
|第三步|**Host + Cookie + HTTP 请求**|告诉服务器"我要什么"|到店后报出店名 + 出示会员卡|
|第四步|**HTTP 响应**|服务器把数据交给你|店员把商品递到你手上|
|第五步|**浏览器渲染**|把代码变成你看到的页面|把原料加工成成品|
|第六步|**TCP**|通信结束，礼貌断开|挂电话|

---

### 一张图记住核心关系

```
DNS（找到路）→ TCP（接通电话）→ HTTP 请求（说"我要什么"）
                                       ↑
                                  Host + Cookie
                                  （去哪家店 + 我是谁）
→ HTTP 响应（拿到数据）→ 浏览器渲染（看到页面）→ TCP 断开（挂电话）
```

这就是从你按下回车键到网页出现在屏幕上的完整故事。每一个概念都不是孤立的，它们在各自的环节各司其职，共同完成了一次 Web 通信。
