在C语言中，主函数main是程序的入口点。根据C语言的标准，main函数应该返回一个int类型的值，并且可以接受两个参数：argc和argv。以下是三种常见的main函数声明方式：
```
第一个：int main()

第二个：int main(int argc, char *argv[])

第三个：void main()
```

```
int main() {

    // 程序代码

    return 0;

}
```
这是最简单的main函数声明方式。它不接收任何参数。根据C标准，main函数应该返回一个整数，通常情况下，返回0表示程序成功执行，非0值表示程序异常终止。

```
int main(int argc, char *argv[]) {

    // 程序代码

    return 0;

}
```
这种声明方式允许程序接收命令行参数。argc是参数的数量，argv是一个字符串数组，包含了每个参数的值。argv[0]通常是程序的名字。

```
void main() {

    // 程序代码

}
```
这种声明方式在C标准中是未定义的，也就是说，它不是标准的C语言写法。虽然一些编译器可能允许这种写法，但它并不符合C语言的标准。在标准C中，main函数应该返回一个int类型的值。


### 注意事项：###

**返回值**：无论哪种声明方式，main函数都应该返回一个整数。如果省略return语句，C标准规定程序在main函数结束时隐式返回0。

**标准合规**：为了确保程序的可移植性和标准合规性，建议使用int main()或int main(int argc, char *argv[])。

**编译器差异**：不同的编译器可能对非标准写法（如void main()）有不同的处理方式，但为了兼容性和规范性，应避免使用。

在实际编程中，应尽量遵循C语言的标准，使用**int main()** 或 **int main(int argc, char *argv[])** 作为程序的入口点。
