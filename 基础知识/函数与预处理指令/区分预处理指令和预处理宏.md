

## 一句话区分

> **预处理指令**是"动作"（你让预处理器**做什么**），**预处理宏**是"产物"（通过 `#define` **定义出来的东西**）。

---

## 类比理解

| 概念    | 类比                      | 特征               | 标志                 |
| ----- | ----------------------- | ---------------- | ------------------ |
| 预处理指令 | 你对快递员说的指令："把这个包裹送到XX地址" | 有明确的**动作**       | 以 `#` 开头           |
| 预处理宏  | 你给外卖写的备注："送到3楼左手边"      | 只是一个**名字→内容**的映射 | 代码中直接写名字，预处理阶段自动替换 |

---

## 预处理指令 = 全部 `#` 开头的命令

```c
#include <stdio.h>    // ← 指令：包含文件
#define PI 3.14       // ← 指令：定义一个宏
#undef PI             // ← 指令：取消宏定义
#if defined(X)        // ← 指令：条件判断
#ifdef DEBUG          // ← 指令：条件判断
#ifndef HEADER_H      // ← 指令：条件判断
#elif ...             // ← 指令：条件分支
#else                 // ← 指令：条件分支
#endif                // ← 指令：结束条件块
#error "stop!"        // ← 指令：报错
#pragma once          // ← 指令：编译器特定操作
#line 100             // ← 指令：修改行号
#                     // ← 指令：空指令
```

以上 **每一个 `#` 开头的行**都是预处理指令，它们是预处理器能"听懂"的全部命令。

---

## 预处理宏 = `#define` 创造出来的"名字→替换文本"

宏是 `#define` 指令的**产物**，它本身不是指令，而是一条**替换规则**：

```c
// ---- 对象宏 ----
#define PI 3.14159           // 宏名: PI，替换为: 3.14159
#define MAX_SIZE 1024        // 宏名: MAX_SIZE，替换为: 1024
#define DEBUG                // 宏名: DEBUG，无替换文本（仅做标记）

// ---- 函数宏 ----
#define SQUARE(x) ((x)*(x))  // 宏名: SQUARE(x)，替换为: ((x)*(x))
#define MAX(a,b) ((a)>(b)?(a):(b))
```

宏被创建后，**在代码中直接写名字就会被替换**，不需要 `#`：

```c
double circle = 2 * PI * r;      // PI → 3.14159
int buf[MAX_SIZE];               // MAX_SIZE → 1024
int result = SQUARE(3 + 1);      // SQUARE(3+1) → ((3+1)*(3+1))
```

## 它们的关系

```
┌─────────────────────────────────────────┐
│            预处理指令（17种）              │
│                                         │
│   #include    → 包含文件                 │
│   #define     → 定义宏 ←──── 宏在这里诞生 │
│   #undef      → 取消宏                   │
│   #if / #ifdef / #ifndef / ...          │
│   #error / #warning / #pragma / #line   │
│   #elifdef / #elifndef (C23)            │
│   # (空指令)                              │
└─────────────────────────────────────────┘

宏（由 #define 创建）：
  • 对象宏：  PI → 3.14159
  • 函数宏：  SQUARE(x) → ((x)*(x))
  • 标记宏：  DEBUG → （空）
```

**一句话总结关系**：`#define` 是指令，用它定义出来的东西叫宏。就像"出生"是动作，"孩子"是产物。

## 快速自测

看到下面这些，你能分清哪些是指令、哪些是宏吗？

```c
#include <stdio.h>        // 指令 ✓  （包含文件）
#define PI 3.14           // 指令 ✓  （定义宏的动作）
                          // 宏   ✓  （PI 是被定义出来的宏）
#ifdef PI                 // 指令 ✓  （条件判断）
double area = PI * r * r; // 宏   ✓  （PI 被替换为 3.14）
#endif                    // 指令 ✓  （结束条件块）
#undef PI                 // 指令 ✓  （取消宏的动作）
```

## 容易混淆的点

| 容易混的场景                         | 正确理解                                                |
| ------------------------------ | --------------------------------------------------- |
| `#define` 到底是指令还是宏？            | `#define` 本身是**指令**，它定义出来的 `PI`、`SQUARE(x)` 才是**宏** |
| `#ifdef DEBUG` 中的 `DEBUG` 是什么？ | `DEBUG` 是一个**宏**（标记宏），`#ifdef` 是**指令**在检查这个宏是否存在    |
| `__FILE__`、`__LINE__` 是什么？     | 它们是**预定义宏**（编译器自动帮你 `#define` 好的），不是指令              |
| `defined()` 是什么？               | 它是 `#if` 指令内部使用的**操作符**，既不是指令也不是宏                   |

简单记：**带 `#` 的是指令，不带 `#` 但在代码中被替换的是宏**。
