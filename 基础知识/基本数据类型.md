## 1. 核心基本类型速查

## 2. 关键类型深度解析

### 2.1 `char` 的本质

`char` 在 C 语言中本质上是**整数类型**，存储的是字符的 ASCII 码（或执行字符集的编码值）。其是否有符号（`signed` / `unsigned`）是**实现定义的**：

- x86/x64 上的 GCC、Clang、MSVC：`char` 通常为 `signed char`
- ARM 上的 GCC：`char` 通常为 `unsigned char`

**可移植代码建议**：若用于存储字符，直接用 `char` 即可；若用于小整数运算，应明确指定 `signed char` 或 `unsigned char`。

**运行时判断 `char` 的符号性**：

```c
#include <limits.h>
#include <stdio.h>

int main(void) {
    // 方法一：编译期判断（预处理器）
#if CHAR_MIN == 0
    printf("char is unsigned\n");
#else
    printf("char is signed\n");
#endif

    // 方法二：运行时判断
    if ((char)-1 < 0) {
        printf("char is signed\n");
    } else {
        printf("char is unsigned\n");
    }
    return 0;
}
```

### 2.2 `int` 的"自然大小"

`int` 被设计为**机器处理效率最高的整数类型**，通常等于 CPU 字长或字长的一半。在现代 32/64 位系统上，`int` 几乎总是 4 字节（32 位）。

### 2.3 `%d` 与 `%i` 的区别

- **`printf` 中**：`%d` 和 `%i` 完全等价，都以十进制输出有符号整数。
- **`scanf` 中**：`%d` 只识别十进制输入；`%i` 能自动识别进制前缀——`0` 开头识别为八进制，`0x` 开头识别为十六进制。

```c
int a, b;
scanf("%d", &a);  // 输入 012 → a = 12（十进制）
scanf("%i", &b);  // 输入 012 → b = 10（八进制 012 = 十进制 10）
```

## 3. 可移植整数类型 `<stdint.h>`（C99）

这是现代 C 编程的关键补充。在需要明确位宽的场合（网络协议、文件格式、硬件交互），**强烈建议使用这些类型**。

### 3.1 类型分类

|类别|命名模式|保证|
|---|---|---|
|固定宽度类型|`int8_t`、`uint32_t` 等|精确等于指定位宽（若平台支持）|
|最小宽度类型|`int_least8_t` 等|至少达到指定宽度，可能更大|
|最快宽度类型|`int_fast8_t` 等|当前平台下运算最快的、不小于指定宽度的类型|
|指针宽度类型|`intptr_t` / `uintptr_t`|大小与平台指针位数一致|

### 3.2 固定宽度类型

|类型|字节数|取值范围|推荐格式宏|
|---|---|---|---|
|`int8_t`|1|−128 ~ 127|`PRId8`|
|`uint8_t`|1|0 ~ 255|`PRIu8`|
|`int16_t`|2|−32,768 ~ 32,767|`PRId16`|
|`uint16_t`|2|0 ~ 65,535|`PRIu16`|
|`int32_t`|4|−2,147,483,648 ~ 2,147,483,647|`PRId32`|
|`uint32_t`|4|0 ~ 4,294,967,295|`PRIu32`|
|`int64_t`|8|−9,223,372,036,854,775,808 ~ 9,223,372,036,854,775,807|`PRId64`|
|`uint64_t`|8|0 ~ 18,446,744,073,709,551,615|`PRIu64`|

### 3.3 指针宽度类型

|类型|字节数|取值范围|推荐格式宏|
|---|---|---|---|
|`intptr_t`|4/8|与平台指针一致|`PRIdPTR`|
|`uintptr_t`|4/8|与平台指针一致|`PRIuPTR`|

### 3.4 最小宽度与最快宽度类型

|类型|保证|典型实现|
|---|---|---|
|`int_least8_t`|至少 8 位|通常为 `signed char`|
|`int_least16_t`|至少 16 位|通常为 `short`|
|`int_least32_t`|至少 32 位|通常为 `int`|
|`int_fast8_t`|至少 8 位，最快|可能为 `int`（即使 `char` 也是 8 位）|
|`int_fast16_t`|至少 16 位，最快|可能为 `int` 或 `long`|
|`int_fast32_t`|至少 32 位，最快|可能为 `int` 或 `long`|

### 3.5 格式宏的正确用法

`<inttypes.h>` 中定义的格式宏是**字符串字面量**，需要与格式字符串拼接使用：

```c
#include <stdio.h>
#include <stdint.h>
#include <inttypes.h>

int main(void) {
    uint8_t  a = 255;
    int32_t  b = -100000;
    uint64_t c = 18446744073709551615ULL;
    intptr_t d = (intptr_t)&a;

    printf("uint8_t:  %" PRIu8  "\n", a);
    printf("int32_t:  %" PRId32 "\n", b);
    printf("uint64_t: %" PRIu64 "\n", c);
    printf("intptr_t: %" PRIdPTR "\n", d);

    return 0;
}
```

> **为什么需要格式宏？** 因为 `int32_t` 在不同平台上可能是 `int`、`long` 或 `short` 的别名，直接用 `%d` 或 `%ld` 不能保证跨平台正确。格式宏在预处理阶段展开为当前平台正确的格式说明符。

### 3.6 底层实现关系

在几乎所有现代编译器中，这些类型的底层实现为：

|固定宽度类型|通常的底层类型|
|---|---|
|`int8_t` / `uint8_t`|`signed char` / `unsigned char`|
|`int16_t` / `uint16_t`|`signed short` / `unsigned short`|
|`int32_t` / `uint32_t`|`signed int` / `unsigned int`|
|`int64_t` / `uint64_t`|`signed long long` / `unsigned long long`|

但 C 标准**不强制**这一映射，只要求这些类型存在且具有指定位宽。

## 4. 类型提升规则

### 4.1 整数提升（Integer Promotion）

在表达式求值和函数调用时，小于 `int` 的整数类型会被自动提升：

|原始类型|提升为|条件|
|---|---|---|
|`char`、`signed char`、`unsigned char`|`int`|若 `int` 能完整表示原类型的所有值（几乎总是成立）|
|`short`、`unsigned short`|`int`|同上|
|`_Bool`|`int`|—|
|位域（bit-field）|`int` 或 `unsigned int`|取决于位域的类型和宽度|

> **关键澄清**：`unsigned char`（0~255）的所有值都能被 `int`（通常 −21亿~21亿）完整表示，因此提升后的类型是 **`int`（有符号）**，而非 `unsigned int`。

### 4.2 浮点提升（Floating Promotion）

|原始类型|提升为|
|---|---|
|`float`|`double`|

### 4.3 触发场景

- **可变参数函数**：`printf`、`scanf`、`sprintf` 等（`...` 之前的参数不受影响）
- **二元运算符**：`+`、`-`、`*`、`/`、`%`、`&`、`|`、`^`、`<<`、`>>` 等，两侧操作数先统一为较大类型
- **条件表达式**：`? :` 的第二、第三操作数
- **一元运算符**：`~`（按位取反）

### 4.4 对 `printf` 的影响

```c
#include <stdio.h>
#include <stdint.h>

int main(void) {
    uint8_t a = 255;

    // a 被提升为 int（有符号），值为 255
    // %hhu 是标准写法（告知 printf 按 unsigned char 理解）
    printf("%hhu\n", a);   // 输出: 255

    // %u 在实践中也能工作，因为 255 的 int 表示与 unsigned int 表示相同
    printf("%u\n", a);     // 输出: 255（可行，但严格来说类型不匹配）

    return 0;
}
```

**最佳实践**：始终使用与原始类型对应的格式说明符或格式宏，确保可移植性。

## 6. `printf` 格式化输出详解

### 6.1 格式说明符通用语法

```
%[flags][width][.precision][length]specifier
```

### 6.2 标志（Flags）

|标志|含义|示例|
|---|---|---|
|`-`|左对齐（默认右对齐）|`printf("%-5d", 123);` → `"123 "`|
|`+`|有符号值强制显示正负号|`printf("%+d", 5);` → `"+5"`|
|（空格）|正数前加空格，负数显示负号|`printf("% d", 5);` → `" 5"`|
|`#`|添加进制前缀或强制小数点|`printf("%#x", 100);` → `"0x64"`|
|`0`|用 `0` 填充（与 `-` 冲突时 `0` 被忽略）|`printf("%05d", 6);` → `"00006"`|

**`#` 标志的细节**：

```c
printf("%#o\n", 100);   // "0144"（添加八进制前缀 0）
printf("%#x\n", 100);   // "0x64"（添加十六进制前缀 0x）
printf("%#X\n", 100);   // "0X64"（添加十六进制前缀 0X）
printf("%.0f\n", 100.0); // "100."（强制显示小数点，即使无小数位）
```

### 6.3 宽度（Width）

|语法|含义|示例|
|---|---|---|
|`%5d`|最小宽度 5，不足补空格|`printf("%5d", 6);` → `" 6"`|
|`%-5d`|最小宽度 5，左对齐|`printf("%-5d", 6);` → `"6 "`|
|`%05d`|最小宽度 5，不足补零|`printf("%05d", 6);` → `"00006"`|
|`%*d`|宽度由参数指定|`printf("%*d", 5, 6);` → `" 6"`|

> 若实际内容的宽度超过指定宽度，则按实际宽度完整输出，不会被截断。

### 6.4 精度（Precision）

精度的含义**取决于数据类型**：

|类型|精度含义|示例|
|---|---|---|
|整数（`d`、`i`、`u`、`o`、`x`、`X`）|最少显示的数字位数，不足补前导零|`printf("%.3d", 6);` → `"006"`|
|浮点数（`f`、`F`）|小数点后的位数|`printf("%.2f", 3.14159);` → `"3.14"`|
|浮点数（`e`、`E`）|小数点后的位数|`printf("%.2e", 3.14159);` → `"3.14e+00"`|
|浮点数（`g`、`G`）|有效数字的最大位数|`printf("%.5g", 3.14159);` → `"3.1416"`|
|字符串（`s`）|最大输出字符数（截断）|`printf("%.5s", "HelloWorld");` → `"Hello"`|

### 6.5 长度修饰符（Length）

|修饰符|含义|配合的说明符|
|---|---|---|
|`hh`|`signed char` / `unsigned char`|`d`、`i`、`u`、`o`、`x`、`X`、`n`|
|`h`|`short` / `unsigned short`|`d`、`i`、`u`、`o`、`x`、`X`、`n`|
|`l`|`long` / `unsigned long`|`d`、`i`、`u`、`o`、`x`、`X`、`n`|
|`ll`|`long long` / `unsigned long long`|`d`、`i`、`u`、`o`、`x`、`X`、`n`|
|`l`|`double`（`f`、`F`、`e`、`E`、`g`、`G` 的输入）|`f`、`e`、`g` 等（`scanf` 中）|
|`L`|`long double`|`f`、`F`、`e`、`E`、`g`、`G`、`a`、`A`|
|`z`|`size_t` / `ssize_t`|`d`、`i`、`u`、`o`、`x`、`X`|
|`t`|`ptrdiff_t`|`d`、`i`、`u`、`o`、`x`、`X`|
|`j`|`intmax_t` / `uintmax_t`|`d`、`i`、`u`、`o`、`x`、`X`|

### 6.6 转换说明符（Specifier）

|说明符|含义|示例|
|---|---|---|
|`d` / `i`|有符号十进制整数|`printf("%d", -42);` → `"-42"`|
|`u`|无符号十进制整数|`printf("%u", 42U);` → `"42"`|
|`o`|无符号八进制|`printf("%o", 100);` → `"144"`|
|`x`|无符号十六进制（小写）|`printf("%x", 255);` → `"ff"`|
|`X`|无符号十六进制（大写）|`printf("%X", 255);` → `"FF"`|
|`f` / `F`|浮点数（定点表示）|`printf("%f", 3.14);` → `"3.140000"`|
|`e` / `E`|浮点数（科学计数法）|`printf("%e", 314.0);` → `"3.140000e+02"`|
|`g` / `G`|自动选择 `f` 或 `e`，去除无意义的零|`printf("%g", 123.457);` → `"123.457"`|
|`a` / `A`|十六进制浮点数（C99）|`printf("%a", 3.14);` → `"0x1.91eb85p+1"`|
|`c`|单个字符|`printf("%c", 'A');` → `"A"`|
|`s`|字符串|`printf("%s", "Hi");` → `"Hi"`|
|`p`|指针地址|`printf("%p", (void*)&x);` → `"0x7ffeed..."`|
|`n`|已输出的字符数（写入参数）|见下方说明|
|`%`|输出字面量 `%`|`printf("%%");` → `"%"`|

### 6.7 关于 `%n` 说明符

`%n` 是 `printf` 中唯一**不输出内容、而是写入数据**的说明符。它将到目前为止已输出的字符数写入对应的 `int *` 参数：

```c
int count;
printf("Hello%n World\n", &count);
// 输出: "Hello World"
// count 的值 = 5（"Hello" 共 5 个字符）
```

> **安全警告**：`%n` 可被利用进行格式化字符串攻击（Format String Attack）。在现代代码中应避免使用。许多编译器提供 `-Wformat-security` 警告选项来检测潜在的格式化字符串漏洞。

### 6.8 宽度与精度的组合

```c
// 总宽度 10，小数 3 位，右对齐，空格填充
printf("%10.3f\n", 3852.99);   // "  3852.990"

// 总宽度 10，小数 3 位，右对齐，零填充
printf("%010.3f\n", 3852.99);  // "003852.990"

// 变量宽度 + 变量精度
int w = 10, p = 3;
printf("%*.*f\n", w, p, 3852.99);  // "  3852.990"
```

> **注意**：宽度包括小数点和小数部分的所有字符。当同时指定宽度和精度时，精度先确定数值的表示形式，宽度再决定整体的对齐和填充。

## 7. 常见陷阱与注意事项

### 7.1 类型不匹配导致的未定义行为

```c
long long x = 42;
printf("%d\n", x);  // 未定义行为！%d 期望 int，但传入了 long long
// 正确写法：
printf("%lld\n", x);
```

### 7.2 `float` 传给 `printf` 时的提升

```c
float f = 3.14f;
printf("%f\n", f);   // 正确：float 被提升为 double，%f 接受 double
printf("%lf\n", f);  // 也可行：C99 起 %lf 在 printf 中等价于 %f
```

但在 `scanf` 中：

```c
float f;
double d;
scanf("%f", &f);   // 正确：%f 读入 float
scanf("%lf", &d);  // 正确：%lf 读入 double
scanf("%f", &d);   // 错误！%f 期望 float*，但传入了 double*，导致内存写入错误
```

### 7.3 `size_t` 的格式说明符

```c
printf("%d\n", sizeof(int));   // 错误！sizeof 返回 size_t，不是 int
printf("%zu\n", sizeof(int));  // 正确
```

### 7.4 字符数组与 `scanf` 的缓冲区溢出

```c
char buf[10];
scanf("%s", buf);       // 危险！输入超过 9 个字符会溢出
scanf("%9s", buf);      // 安全：限制最多读取 9 个字符 + '\0'
```

### 7.5 浮点数比较

```c
double a = 0.1 + 0.2;
double b = 0.3;
if (a == b) { ... }  // 几乎必然失败！
// 正确做法：
#include <math.h>
if (fabs(a - b) < 1e-9) { ... }
```

## 9. 完整代码示例

```c
#include <stdio.h>
#include <limits.h>
#include <float.h>
#include <stdint.h>
#include <inttypes.h>
#include <stddef.h>

int main(void) {
    // === 基本类型与 limits.h ===
    printf("=== Integer Limits ===\n");
    printf("char:   %d to %d\n", CHAR_MIN, CHAR_MAX);
    printf("int:    %d to %d\n", INT_MIN, INT_MAX);
    printf("long:   %ld to %ld\n", LONG_MIN, LONG_MAX);
    printf("ullong: 0 to %llu\n", ULLONG_MAX);

    // === 浮点类型与 float.h ===
    printf("\n=== Float Limits ===\n");
    printf("float:  %e to %e (%d digits)\n", FLT_MIN, FLT_MAX, FLT_DIG);
    printf("double: %e to %e (%d digits)\n", DBL_MIN, DBL_MAX, DBL_DIG);
    printf("FLT_EPSILON: %e\n", FLT_EPSILON);
    printf("DBL_EPSILON: %e\n", DBL_EPSILON);

    // === stdint.h 固定宽度类型 ===
    printf("\n=== Fixed-Width Types ===\n");
    uint8_t  u8  = 255;
    int32_t  i32 = -100000;
    uint64_t u64 = UINT64_MAX;

    printf("uint8_t:  %" PRIu8  "\n", u8);
    printf("int32_t:  %" PRId32 "\n", i32);
    printf("uint64_t: %" PRIu64 "\n", u64);

    // === size_t 与 ptrdiff_t ===
    printf("\n=== Special Types ===\n");
    printf("sizeof(int) = %zu bytes\n", sizeof(int));
    printf("sizeof(double) = %zu bytes\n", sizeof(double));

    int arr[] = {10, 20, 30, 40, 50};
    ptrdiff_t diff = &arr[4] - &arr[0];
    printf("pointer diff = %td elements\n", diff);

    // === printf 格式化技巧 ===
    printf("\n=== Formatting ===\n");
    printf("right-align:  |%10d|\n", 42);
    printf("left-align:   |%-10d|\n", 42);
    printf("zero-pad:     |%010d|\n", 42);
    printf("show-sign:    |%+d| |+d|\n", 42, -42);
    printf("hex-prefix:   %#x\n", 255);
    printf("precision-d:  %.5d\n", 42);
    printf("precision-f:  %.2f\n", 3.14159);
    printf("precision-s:  %.5s\n", "HelloWorld");
    printf("combined:     |%10.3f|\n", 3.14159);

    return 0;
}
```

## 10. 总结

|核心原则|说明|
|---|---|
|位宽明确时用 `<stdint.h>`|网络协议、文件格式、硬件寄存器操作|
|通用计算用基本类型|`int`、`double` 通常是最佳默认选择|
|格式说明符必须匹配类型|不匹配是未定义行为，不是"碰巧能工作"|
|跨平台输出用 `<inttypes.h>` 格式宏|`PRId32`、`PRIu64` 等比 `%d`、`%llu` 更安全|
|`size_t` 用 `%zu`，`ptrdiff_t` 用 `%td`|不要用 `%d` 或 `%u` 输出 `sizeof` 的结果|
|浮点数不要直接 `==` 比较|使用 `fabs(a - b) < epsilon`|
|优先使用 `<limits.h>` / `<float.h>` 的宏|比硬编码数值更安全、更可移植|
