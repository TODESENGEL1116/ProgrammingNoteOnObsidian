### 1.1 分类图例

| 颜色  | 类别    | 包含的运算符                                                                |
| --- | ----- | --------------------------------------------------------------------- |
| 🟦  | 算术运算符 | `+` `-` `*` `/` `%` `++` `--` 一元`+` 一元`-`                             |
| 🟥  | 关系运算符 | `>` `>=` `<` `<=` `==` `!=`                                           |
| 🟩  | 赋值运算符 | `=` `+=` `-=` `*=` `/=` `%=` `<<=` `>>=` `&=` `^=` `\|=`              |
| 🟧  | 逻辑运算符 | `&&` `\|` `!`                                                         |
| 🟪  | 位运算符  | `&` `\|` `^` `~` `<<` `>>`                                            |
| ⬜   | 其他运算符 | `[]` `.` `->` `()` `sizeof` `?:` `,` `*`（解引用） `&`（取地址） `(type)`（强制转换） |

### 1.2 计算型 vs 赋值型

|类型|特征|示例|
|---|---|---|
|**计算型运算符**|仅生成结果，**不修改**原变量|`a + b`、`x * 2`、`i++`（返回旧值，但 `i` 本身被修改——这是特例）|
|**赋值型运算符**|将计算结果**写入**变量，修改原变量的值|`a = 10`、`total += price`、`flags \|= 0x01`|

> 严格来说，`++`/`--` 既有计算行为（产生值）也有副作用（修改变量），属于兼具两者特征的运算符。

## 2. 运算符优先级排名表（从高到低）

> **阅读说明**：
> 
> - 优先级数字越小，优先级越高。
> - **结合性**决定同级运算符的运算方向：左结合 → 从左到右；右结合 → 从右到左。
> - **元数**：一元 = 1 个操作数；二元 = 2 个操作数；三元 = 3 个操作数。

| 优先级 | 运算符                         | 类别     | 元数  | 结合性 | 名称      | 示例                       | 说明                                      |
| --- | --------------------------- | ------ | --- | --- | ------- | ------------------------ | --------------------------------------- |
| 1   | `()`                        | ⬜ 其他   | —   | —   | 括号/函数调用 | `(a + b)`、`func(x)`      | 强制改变运算顺序；函数调用                           |
| 1   | `[]`                        | ⬜ 其他   | 二元  | 左结合 | 数组下标    | `arr[i]`                 | 访问数组元素                                  |
| 1   | `.` `->`                    | ⬜ 其他   | 二元  | 左结合 | 成员访问    | `obj.name`、`ptr->age`    | `.` 用于结构体变量，`->` 用于结构体指针                |

| 3   | `*` `/` `%`                 | 🟦 算术  | 二元  | 左结合 | 乘、除、取模  | `a * b`、`n % 2`          | `%` 仅用于整数；`/` 对整数做截断除法                  |

## 3. 关键细节深度解析

### 3.1 后置 `++`/`--` 与前置 `++`/`--` 的区别

虽然它们在优先级表中都位于高位，但语义完全不同：

```c
int i = 5;
int a = i++;   // a = 5, i = 6（先用后加）
int b = ++i;   // b = 7, i = 7（先加后用）
```

|形式|优先级|结合性|返回值|副作用|
|---|---|---|---|---|
|`i++`（后置）|第 1 级（最高）|左结合|递增**前**的旧值|变量 +1|
|`++i`（前置）|第 2 级|右结合|递增**后**的新值|变量 +1|

> 在独立语句中（如 `i++;`），两者效果完全相同。区别仅在**表达式中需要用到返回值**时才体现。

### 3.2 `sizeof` 运算符

`sizeof` 是**编译期运算符**（变长数组 VLA 除外），它不执行表达式，只查询类型或表达式结果的大小：

```c
int x = 10;
printf("%zu\n", sizeof(int));      // 输出: 4
printf("%zu\n", sizeof x);         // 输出: 4（不需要括号，因为操作数是变量）
printf("%zu\n", sizeof(x + 3.14)); // 输出: 8（x 被提升为 double，但不实际计算 x+3.14）

// VLA 例外：运行时求值
int n = 5;
int arr[n];
printf("%zu\n", sizeof(arr));      // 输出: 20（5 × 4）
```

> `sizeof` 的返回类型是 `size_t`（无符号整数），输出时应使用 `%zu`。

### 3.3 短路求值（Short-Circuit Evaluation）

逻辑运算符 `&&` 和 `||` 具有短路特性：

```c
// && 短路：左侧为假（0），右侧不再求值
int x = 0;
if (x != 0 && 10 / x > 1) { ... }  // 安全！x!=0 为假，10/x 不会被执行

// || 短路：左侧为真（非0），右侧不再求值
int *ptr = NULL;
if (ptr == NULL || *ptr > 0) { ... }  // 安全！ptr==NULL 为真，*ptr 不会被解引用
```

> 这意味着 `&&` 和 `||` **不保证**右侧表达式一定被求值，这与算术运算符和位运算符不同。

### 3.4 条件运算符 `?:` 的右结合性

```c
// 右结合意味着从右到左分组
int result = a > b ? a : b > c ? b : c;
// 等价于：
int result = a > b ? a : (b > c ? b : c);
// 即：求 a、b、c 三个数中的最大值
```

### 3.5 赋值运算符的右结合性

```c
// 右结合意味着从右到左分组
int a, b, c;
a = b = c = 10;
// 等价于：
a = (b = (c = 10));
// 三个变量都被赋值为 10
```

### 3.6 逗号运算符的完整说明

逗号运算符**从左到右**依次求值每个子表达式，**丢弃**前面所有表达式的结果，**返回**最后一个表达式的值。

```c
// 基本用法
int a = (1 + 2, 3 + 4, 5 + 6);  // a = 11（最后一个表达式的值）

// for 循环中同时控制多个变量
for (int i = 0, j = 10; i < j; i++, j--) {
    printf("i=%d, j=%d\n", i, j);
}
```

> **注意区分**：逗号运算符（`,`）与**分隔符逗号**是不同的。函数参数列表、变量声明列表、初始化列表中的逗号是**语法分隔符**，不是逗号运算符：
> 
> ```c
> int a = 1, b = 2;              // 这里的逗号是分隔符，不是逗号运算符
> printf("%d %d\n", a, b);       // 这里的逗号是分隔符
> int c = (a = 3, a + 1);        // 这里的逗号是逗号运算符，c = 4
> ```

### 3.7 位运算符的常见应用

```c
// 判断奇偶
if (n & 1) { /* n 是奇数 */ }

// 左移/右移 ≈ 乘/除 2 的幂
int x = 10;
int y = x << 1;   // y = 20（10 × 2¹）
int z = x >> 1;   // z = 5 （10 / 2¹）

// 设置特定位（置 1）
int flags = 0;
flags |= (1 << 3);   // 第 3 位置 1 → flags = 0b00001000 = 8

// 清除特定位（置 0）
flags &= ~(1 << 3);  // 第 3 位置 0 → flags = 0

// 检查特定位
if (flags & (1 << 3)) { /* 第 3 位为 1 */ }

// 翻转特定位
flags ^= (1 << 3);    // 第 3 位取反

// 用异或交换两数（不借助临时变量）
int a = 5, b = 9;
a ^= b;
b ^= a;
a ^= b;
// 现在 a = 9, b = 5
```

## 4. 转义字符完全参考

### 4.1 简单转义序列

所有 C 标准版本均支持，含义一致。

|转义序列|名称|ASCII 值|功能与示例|
|---|---|---|---|
|`\'`|单引号|0x27|在字符常量中表示单引号：`'\''`|
|`\"`|双引号|0x22|在字符串中表示双引号：`"She said, \"Hi\""`|
|`\?`|问号|0x3F|防止三字符序列被误解释（C17 后三字符序列已移除，主要用于兼容旧代码）|
|`\\`|反斜杠|0x5C|表示反斜杠本身：`"C:\\Windows\\System32"`|
|`\a`|响铃|0x07|终端蜂鸣提示：`printf("\a");`|
|`\b`|退格|0x08|光标回退一格：`"abc\b\bxy"` 可能显示为 `axy`（依赖终端）|
|`\f`|换页|0x0C|打印机换页；终端下通常表现为清屏，现代使用较少|
|`\n`|换行|0x0A|光标移到下一行行首。文本模式下会被转换为系统换行序列（Windows 为 `\r\n`）|
|`\r`|回车|0x0D|光标移到当前行行首；常与 `\n` 组合为 `\r\n`|
|`\t`|水平制表|0x09|跳到下一个制表位：`"Name\tAge\n"`|
|`\v`|垂直制表|0x0B|纵向制表；终端行为实现定义，很少使用|

```c
// 综合示例
printf("Line1\nLine2\n");           // 两行输出
printf("Name\tAge\n");              // 制表对齐
printf("C:\\Users\\test\n");        // 输出: C:\Users\test
printf("He said, \"Hello!\"\n");    // 输出: He said, "Hello!"
```

### 4.2 数值转义序列

#### 八进制转义 `\nnn`

- 形式：`\` 后跟 **1~3 位**八进制数字（0~7）。
- 值为对应编码值的字符。

```c
char c1 = '\0';       // 空字符（字符串结束符）
char c2 = '\123';     // 八进制 123 = 十进制 83 = ASCII 'S'
char c3 = '\177';     // 八进制 177 = 十进制 127 = DEL

// 关键：最多只"吃"3 位八进制数字
char s[] = "\1234";   // '\123'（'S'）+ '4'，不是 '\1234'
```

> **边界规则**：`\` 后最多读取 3 位八进制数字（0~7），遇到非八进制数字立即停止。

#### 十六进制转义 `\xn...`

- 形式：`\x` 后跟 **任意多位**十六进制数字（0~9, a~f, A~F）。
- 值为对应编码值的字符。

```c
char c1 = '\x41';     // 十六进制 41 = 十进制 65 = ASCII 'A'
char c2 = '\x1b';     // ESC 控制字符

// 关键：\x 会"贪婪"吃掉所有连续的十六进制数字！
char s[] = "\x41bc";  // 这是一个完整的十六进制转义 \x41bc（= 0x41BC = 16828）
                       // 而不是 '\x41' + 'b' + 'c'！

// 正确拆分方法：用字符串拼接
char s2[] = "\x41" "bc";  // '\x41'（'A'）+ 'b' + 'c' → "Abc"
```

> **⚠️ 重要陷阱**：十六进制转义没有位数上限，会一直读取直到遇到非十六进制字符。如果值超过 `char` 的表示范围，结果是**实现定义的**。实践中务必注意拆分。

### 4.3 通用字符名（Unicode 转义，C99 起）

|形式|含义|十六进制位数|
|---|---|---|
|`\uNNNN`|Unicode 码点 U+NNNN|恰好 4 位|
|`\UNNNNNNNN`|Unicode 码点 U+NNNNNNNN|恰好 8 位|

```c
// C99 起支持
const char *s = "\u4e2d\u6587";    // "中文"（UTF-8 编码下每个 \u 对应 3 个字节）
char c = '\u0041';                  // 'A'
```

> **限制**：
> 
> - 不能用于表示基本源字符集中的字符（如 `$`、`@`、`` ` `` 等）。
> - 不能用于表示 C0/C1 控制码。
> - 在窄字符串（`char`）中，一个 `\u` 可能对应多个字节（UTF-8 编码）。

### 4.4 条件转义序列（实现定义）

形式：`\c`，其中 `c` 不属于任何标准转义序列。

- 语义由编译器实现定义，**不可移植**。
- 典型例子：某些编译器支持 `\e` 表示 ESC（0x1B），但这**不是标准 C**。

```c
// 非标准，依赖编译器
printf("\e[31mRed Text\e[0m\n");  // GCC/Clang 通常支持（ANSI 颜色）
```

> **建议**：避免在可移植代码中使用条件转义。若必须使用，应封装为宏并加注释说明。

## 5. 易混淆点辨析

### 5.1 `&` 和 `*` 的双重身份

|运算符|上下文|含义|元数|优先级|
|---|---|---|---|---|
|`&`|一元（如 `&var`）|**取地址**|一元|第 2 级|
|`&`|二元（如 `a & b`）|**按位与**|二元|第 8 级|
|`*`|一元（如 `*ptr`）|**解引用**|一元|第 2 级|
|`*`|二元（如 `a * b`）|**乘法**|二元|第 3 级|

> 编译器根据上下文自动区分，不会混淆。

### 5.2 `+` 和 `-` 的双重身份

|运算符|上下文|含义|元数|优先级|
|---|---|---|---|---|
|`+`|一元（如 `+x`）|正号|一元|第 2 级|
|`+`|二元（如 `a + b`）|加法|二元|第 4 级|
|`-`|一元（如 `-x`）|负号|一元|第 2 级|
|`-`|二元（如 `a - b`）|减法|二元|第 4 级|

### 5.3 `++`/`--` 在表达式中的行为

```c
int i = 5;
int a = i++ + ++i;  // ⚠️ 未定义行为！同一表达式中对 i 多次修改且无序列点

// 安全写法：分开写
int i = 5;
int a = i++;   // a = 5, i = 6
int b = ++i;   // b = 7, i = 7
```

> **规则**：在两个序列点之间，同一个变量最多只能被修改一次，否则是**未定义行为**。

## 7. 常见陷阱汇总

|陷阱|错误写法|正确写法|说明|
|---|---|---|---|
|混淆 `=` 和 `==`|`if (a = 5)`|`if (a == 5)`|`=` 是赋值，`==` 是比较|
|整数除法截断|`1 / 2` → `0`|`1.0 / 2` → `0.5`|整数除法向零截断|
|取模负数|`-7 % 3`|结果为 `-1`（C99 定义向零截断）|C99 前行为实现定义|
|十六进制转义贪婪|`"\x41bc"`|`"\x41" "bc"`|`\x` 会吃掉所有连续十六进制数字|
|八进制转义边界|`"\1234"`|是 `'\123'` + `'4'`|八进制最多 3 位|
|未定义行为|`i++ + ++i`|分两条语句写|同一表达式中不能多次修改同一变量|
|`sizeof` 与 `%d`|`printf("%d", sizeof(int))`|`printf("%zu", sizeof(int))`|`sizeof` 返回 `size_t`，应用 `%zu`|
|短路求值副作用|`i++ && func()`|注意 `func()` 可能不被调用|`&&` 左侧为假时右侧不求值|
