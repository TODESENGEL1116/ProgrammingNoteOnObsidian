

## 1. 基础概念

计算机中常用的四种进制：

| 进制            | 基数  | 使用数字     | 前缀/后缀  | 典型用途             |
| ------------- | --- | -------- | ------ | ---------------- |
| 二进制 (Binary)  | 2   | 0, 1     | 0b 或 B | 计算机底层存储与运算       |
| 八进制 (Octal)   | 8   | 0–7      | 0o 或 O | Unix 文件权限、早期编程语言 |
| 十进制 (Decimal) | 10  | 0–9      | 无      | 人类日常计数           |
| 十六进制 (Hex)    | 16  | 0–9, A–F | 0x 或 H | 内存地址、颜色值、浮点数表示   |

**核心原理：按权展开** 任何进制的数都可以用以下公式表示其十进制值： 
$$ 
N=\sum_{i=-m}^{n} d_i \times R^i
$$ 
- $`R`$：进制基数；
- $`d_i`$：第$i$位数码；
- $`n`$：整数最高位指数；
- $`-m`$：小数最低位指数。

## 2. 十进制 → 其他进制

十进制转其他进制时，整数部分和小数部分需要分别处理，方法完全不同。

### 2.1 整数部分：除基取余法（逆序排列）

**步骤：**

1. 将整数部分不断除以目标进制的基数 $R$。
2. 记录每次的余数。
3. 当商为 0 时停止。
4. 将所有余数从最后一次到第一次逆序排列，即为结果。

记忆口诀：**除基取余，逆序排列。**

示例：十进制 258 转换

```
- 258 ÷ 2 = 129 ... 余 0 ← 最低位 
- 129 ÷ 2 = 64 ... 余 1 
- 64 ÷ 2 = 32 ... 余 0 
- 32 ÷ 2 = 16 ... 余 0 
- 16 ÷ 2 = 8 ... 余 0 
- 8 ÷ 2 = 4 ... 余 0 
- 4 ÷ 2 = 2 ... 余 0 
- 2 ÷ 2 = 1 ... 余 0 
- 1 ÷ 2 = 0 ... 余 1 ← 最高位   
```
结果：$`258_{(10)}=100000010_{(2)}`$

```
258 ÷ 8 = 32 ... 余 2 ← 最低位 32 ÷ 8 = 4 ... 余 0 
4 ÷ 8 = 0 ... 余 4 ← 最高位 
```
结果：$`258_{(10)}=402_{(8)}`$

```
258 ÷ 16 = 16 ... 余 2 ← 最低位 
16 ÷ 16 = 1 ... 余 0 
1 ÷ 16 = 0 ... 余 1 ← 最高位 
```
结果： $`258_{(10)}=102_{(16)}`$



### 2.2 小数部分：乘基取整法（顺序排列）

**步骤：**

1. 将小数部分不断乘以目标进制的基数 $R$。
2. 记录每次乘积的整数部分。
3. 取乘积的小数部分继续乘，直到小数部分为 0 或达到所需精度。
4. 将所有整数部分从第一次到最后一次顺序排列，即为结果。

记忆口诀：**乘基取整，顺序排列。**

> 示例1：$`0.6875_{(10)}`$

```
- 转二进制： 0.6875 × 2 = 1.375 → 取整 1 ← 最高位 
- 0.375 × 2 = 0.75 → 取整 
- 0 0.75 × 2 = 1.5 → 取整 
- 1 0.5 × 2 = 1.0 → 取整 
- 1 ← 最低位（小数部分为0，停止） 
```
结果：$`0.6875_{(10)}=0.1011_{(2)}`$  

```
- 转十六进制： 0.6875 × 16 = 11.0 → 取整 11 = B ← 小数部分为0，
- 停止 
```
结果：$`0.6875_{(10)}=0.\text{B}_{(16)}`$

> 示例2：十进制 0.1 转二进制（无限循环小数） 0.1 × 2 = 0.2 → 0 0.2 × 2 = 0.4 → 0 0.4 × 2 = 0.8 → 0 0.8 × 2 = 1.6 → 1 0.6 × 2 = 1.2 → 1 0.2 × 2 = 0.4 → 0 ← 开始循环 重点：**十进制有限小数，不一定是二进制有限小数**，计算机浮点数会存在精度截断。

### 2.3 完整实例：整数 + 小数

将十进制 $`13.625_{(10)}`$ 转为二进制
整数部分 $`13`$： 
```
- 13 ÷ 2 = 6 ... 余 1 
- 6 ÷ 2 = 3 ... 余 0 
- 3 ÷ 2 = 1 ... 余 1 
- 1 ÷ 2 = 0 ... 余 1  
```
整数结果：$`1101`$

小数部分 $`(0.625)`$：
```  
-  (0.625) × 2 = 1.25 → 1 
- 0.25 × 2 = 0.5 → 0 
- 0.5 × 2 = 1.0 → 1 
```
小数结果：$`101`$
合并结果：$`\boldsymbol{13.625_{(10)}=1101.101_{(2)}}`$

## 3. 其他进制 → 十进制

方法：**按权展开求和** 将每一位数字乘以对应的位权（基数的幂次），然后求和。

例：$1101.101_{(2)}$ 
$$ 
\begin{align*} &1\times 2^3 + 1\times 2^2 + 0\times 2^1 +1\times 2^0 +1\times 2^{-1}+0\times 2^{-2}+1\times 2^{-3}\ =&8+4+0+1+0.5+0+0.125\ =&13.625 \end{align*}
$$

例：$402_{(8)}$ 
$$
4\times8^2+0\times8^1+2\times8^0 = 4\times64+0+2=258
$$

例：$102_{(16)}$ 
$$
1\times16^2+0\times16^1+2\times16^0=256+0+2=258
$$

## 4. 二进制 ↔ 八进制（三位一组）

为什么是三位？ 因为 $`8 = 2^3`$，每一位八进制数恰好对应 3 位二进制数。这种对应关系是精确的、无损的。

对照表：

| 八进制 | 二进制 |
| --- | --- |
| 0   | 000 |
| 1   | 001 |
| 2   | 010 |
| 3   | 011 |
| 4   | 100 |
| 5   | 101 |
| 6   | 110 |
| 7   | 111 |

### 4.1 二进制 → 八进制

**步骤**：以小数点为界，整数部分从右向左、小数部分从左向右，每 3 位分为一组。不足 3 位的用 0 补齐，然后每组直接替换为对应的八进制数字。

示例：$`101110111.01101_{(2)}`$ 
```
分组（整数部分从右向左，小数部分从左向右）： 
整数部分：`010 | 110 | 111` 
小数部分：`011 | 010`（末尾补0）

逐组转换： 
010 → 2     
110 → 6   
111 → 7   
011 → 3      
010 → 2
```
结果：$`\boldsymbol{101110111.01101_{(2)}=267.32_{(8)}}`$
### 4.2 八进制 → 二进制

**步骤**：将每一位八进制数直接展开为 3 位二进制数，然后拼接。
示例：$`57.3_{(8)}`$ 
``` 
5 → 101    
7 → 111 .    
3 → 011
```
拼接结果：$`\boldsymbol{57.3_{(8)}=101111.011_{(2)}}`$

## 5. 二进制 ↔ 十六进制（四位一组）

为什么是四位？ 因为 $`16 = 2^4`$，每一位十六进制数恰好对应 4 位二进制数。

对照表：

|十六进制|二进制|十六进制|二进制|
|---|---|---|---|
|0|0000|8|1000|
|1|0001|9|1001|
|2|0010|A|1010|
|3|0011|B|1011|
|4|0100|C|1100|
|5|0101|D|1101|
|6|0110|E|1110|
|7|0111|F|1111|

### 5.1 二进制 → 十六进制

**步骤**：以小数点为界，整数部分从右向左、小数部分从左向右，每 4 位分为一组。不足 4 位的用 0 补齐，然后每组直接替换为对应的十六进制数字。

示例：$10110111.01101_{(2)}$ 
```
分组：整数部分：`1011 | 0111` 
小数部分：`0110 | 1000`（末尾补0）

逐组转换： 
1011 → B 
0111 → 7 
0110 → 6 
1000 → 8
```

结果：$\boldsymbol{10110111.01101_{(2)}=\text{B7.68}_{(16)}}$

### 5.2 十六进制 → 二进制

**步骤**：将每一位十六进制数直接展开为 4 位二进制数，然后拼接。

示例：$`(\text{0x40C80000})`$     
```
4 → 0100     
0 → 0000 
C → 1100 
8 → 1000 
0 → 0000 
0 → 0000 
0 → 0000 
0 → 0000
```
拼接：`0100 0000 1100 1000 0000 0000 0000 0000`

> 要点：这正是 IEEE 754 浮点数 (\text{0x40C80000}) 的二进制展开，对应十进制的 6.25。十六进制的真正价值在于它是二进制的"紧凑缩写"——32 位二进制只需 8 位十六进制即可表示，且转换过程无需任何计算，纯查表即可完成。

## 6. 八进制 ↔ 十六进制（二进制中转）

八进制和十六进制之间没有直接的分组对应关系（因为 8 和 16 不是彼此的整数次幂），因此最可靠的方法是以二进制为桥梁。

### 6.1 八进制 → 十六进制

步骤：八进制 → 二进制（每位展开为 3 位）→ 十六进制（每 4 位合并）。

示例：$`377_{(8)}`$ 
```
第一步：八进制 → 二进制 
3 → 011 
7 → 111 
7 → 111 
得到：`011111111`

第二步：二进制 → 十六进制（每 4 位一组，从右向左，左侧补0） 
`0000 | 1111 | 1111` 0 | F | F
```
结果：$`\boldsymbol{377_{(8)}=\text{0FF}_{(16)}}`$

### 6.2 十六进制 → 八进制

步骤：十六进制 → 二进制（每位展开为 4 位）→ 八进制（每 3 位合并）。
示例：$`\text{1A3}_{(16)}`$ 
```
第一步：十六进制 → 二进制 
1 → 0001 
A → 1010 
3 → 0011 
得到：`000110100011`

第二步：二进制 → 八进制（每 3 位一组，从右向左，左侧补0） 
`000 | 110 | 100 | 011` 0 | 6 | 4 | 3
```
结果：$`\boldsymbol{\text{1A3}_{(16)}=0643_{(8)}}`$

## 7. 任意进制之间的通用转换

上述方法可以归纳为两条通用路径：

**路径一：以十进制为桥梁** 源进制 → 十进制（按权展开）→ 目标进制（除基取余/乘基取整） 适用于任何两种进制之间的转换，但当目标进制不是 2 的幂次时，计算量较大。

**路径二：以二进制为桥梁（推荐用于 2 的幂次进制之间）** 源进制 ↔ 二进制 ↔ 目标进制 适用于二进制、八进制、十六进制三者之间的互转，全程无需算术运算，只需查表。

路径选择建议：

|源进制|目标进制|推荐路径|
|---|---|---|
|十进制|二/八/十六|除基取余 + 乘基取整|
|二/八/十六|十进制|按权展开求和|
|二 ↔ 八|—|三位一组，直接查表|
|二 ↔ 十六|—|四位一组，直接查表|
|八 ↔ 十六|—|以二进制为桥梁|
|任意 ↔ 任意|—|以十进制为桥梁（通用）|

## 8. 综合演练

> 练习1：十进制 $`42.875_{(10)}`$ 
>
> ```
> 整数部分： 42 ÷ 2 = 21 ... 0 
> 21 ÷ 2 = 10 ... 1 
> 10 ÷ 2 = 5 ... 0 
> 5 ÷ 2 = 2 ... 1 
> 2 ÷ 2 = 1 ... 0 
> 1 ÷ 2 = 0 ... 1 
> 整数二进制：`101010`
> 小数部分： 0.875 × 2 = 1.75 → 1 
> 0.75 × 2 = 1.5 → 1 
> 0.5 × 2 = 1.0 → 1 
> 小数二进制：`111`
> ```
二进制结果：$`\boldsymbol{42.875_{(10)}=101010.111_{(2)}}`$

转八进制（三位一组）： 
```
整数：`101 | 010` → 5 | 2
小数：`111` → 7 
```
八进制结果：$\boldsymbol{42.875_{(10)}=52.7_{(8)}}$

转十六进制（四位一组）：
```
整数：`0010 | 1010` → 2 | A 
小数：`1110`（补0）→ E 
```
十六进制结果：$\boldsymbol{42.875_{(10)}=\text{2A.E}_{(16)}}$


> 练习2：十六进制 $`\text{F3.D}_{(16)}`$ 
> 十六进制 → 二进制（每位展开为 4 位）： 
> ```
> F → 1111 3 → 0011 . 
> D → 1101 
> 二进制：`11110011.1101`
> ```
> 

二进制 → 八进制（三位一组）： 
```
整数（从右向左）：
`011 | 110 | 001` → 3 | 6 | 1 

小数（从左向右）：
`110 | 100`（补0）→ 6 | 4 

```
八进制结果：$`\boldsymbol{\text{F3.D}_{(16)}=361.64_{(8)}}`$

十六进制 → 十进制（按权展开）： 
$$
15\times16^1+3\times16^0 +13\times16^{-1}=240+3+0.8125=\boldsymbol{243.8125_{(10)}}
$$

> 练习3：八进制 $75.4_{(8)}$ 
> 八进制 → 二进制（每位展开为 3 位）： 
> ```
> 7 → 111 5 → 101 . 
> 4 → 100 
> 二进制：`111101.100`
> ```
> 

二进制 → 十六进制（四位一组）： 
```
整数（从右向左）：
`0011 | 1101` → 3 | D 
小数（从左向右）：`1000`（补0）→ 8 
```
十六进制结果：$`\boldsymbol{75.4_{(8)}=\text{3D.8}_{(16)}}`$

八进制 → 十进制（按权展开）： 
$$
7\times8^1+5\times8^0+4\times8^{-1}=56+5+0.5=\boldsymbol{61.5_{(10)}}

## 9. 总结

### 方法速查表

| 转换方向       | 方法                 | 核心操作              |
| ---------- | ------------------ | ----------------- |
| 十进制 → 其他   | 除基取余（整数）+ 乘基取整（小数） | 反复除法/乘法，取余数/整数    |
| 其他 → 十进制   | 按权展开求和             | 每位数字 × 基数的幂次，求和   |
| 二进制 ↔ 八进制  | 三位一组               | $`2^3 = 8`$，精确对应  |
| 二进制 ↔ 十六进制 | 四位一组               | $`2^4 = 16`$，精确对应 |
| 八进制 ↔ 十六进制 | 二进制中转              | 先展开为二进制，再重新分组     |
 
### 核心原则

1. 十进制 ↔ 其他进制：必须经过算术运算（除法、乘法或幂运算）。
2. 2 的幂次进制之间（二、八、十六）：只需分组和查表，无需算术运算，这也是为什么八进制和十六进制在计算机科学中被广泛使用——它们是二进制的**人类友好缩写**。
3. 分组方向：**整数部分从右向左分组，小数部分从左向右分组，不足时用 0 补齐**。
    - 整数缺位：左边补0
    - 小数缺位：右边补0
