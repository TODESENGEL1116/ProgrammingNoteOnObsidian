这两个概念源于计算机中**浮点数的表示方式**（如 IEEE 754 标准）。要理解它们，首先需要了解浮点数的基本结构。

---

### 浮点数的基本结构

一个浮点数由三部分组成：

| 组成部分           | 作用              |
| -------------- | --------------- |
| **符号位（S）**     | 表示正负（0 为正，1 为负） |
| **阶码/指数（E）**   | 表示数量级大小         |
| **尾数/有效数字（M）** | 表示精度            |

---

### 规格化数（Normalized Number）

**定义**：当浮点数的尾数部分满足特定条件（即尾数的最高有效位为 1）时，该浮点数称为规格化数。

**核心思想**：类似于科学计数法中的"标准化"。例如十进制中，我们把 0.0314 写成 $`3.14 \times 10^{-2}`$，让小数点前只有一位非零数字。

在二进制中，规格化意味着尾数的最高位一定是 **1**。既然一定是 1，就不需要存储它了——这就是所谓的**隐含位（Hidden Bit）**或**隐藏位**。

**以 IEEE 754 单精度（32位）为例**：

- 1 位符号位 + 8 位阶码 + 23 位尾数
- 实际尾数为 `1.M`（前面隐含了一个 1），共 24 位有效数字
- 阶码范围：$`1 \leq E \leq 254`$（即不全为 0 也不全为 1）

**规格化数的作用**：

- 最大化表示精度（多出一位隐含位）
- 统一表示形式，便于硬件比较和运算

---

### 非规格化数（Denormalized / Subnormal Number）

**定义**：当浮点数的阶码全为 0 时，该浮点数称为非规格化数。

**核心特点**：

- 隐含位变为 **0**（而不是 1），即尾数为 `0.M`
- 阶码固定为 $`E = 1 - \text{偏移量}`$（单精度中为 $`-126`$）

**以 IEEE 754 单精度为例**：

- 阶码全为 0（E = 0）

**非规格化数的作用**：

- **填补零与最小规格化数之间的空隙**，实现"渐进下溢"（Gradual Underflow）
- 如果没有非规格化数，从 0 到最小规格化数之间会有一个"断层"，任何落在这个区间的数都会被直接截断为 0，造成精度突然丧失
- 非规格化数使得数值可以逐渐趋近于 0，而不是突然跳变

---

### 直观对比

```
数轴上的分布（正数部分）：

非规格化数区间          规格化数区间
|←──── 均匀分布 ────→|←──── 间距逐渐增大 ────→|
0                 最小规格化数            更大的数

非规格化数：间距相等，精度逐渐降低
规格化数：间距随数量级增大而增大，但有效位数恒定
```

---

### 总结

| 特征   | 规格化数         | 非规格化数             |
| ---- | ------------ | ----------------- |
| 阶码   | 不全为 0 且不全为 1 | 全为 0              |
| 隐含位  | 1            | 0                 |
| 表示范围 | 主要数值区间       | 接近 0 的小数区间        |
| 精度   | 恒定（最高）       | 随数值减小而降低          |
| 目的   | 最大化精度和范围     | 消除零附近的"空洞"，实现渐进下溢 |

简单来说，**规格化数是浮点数的"主力军"**，占据了绝大部分表示范围且精度最高；**非规格化数是"辅助部队"**，专门负责在 0 附近提供平滑过渡，避免精度突然丧失。


---
### IEEE 754 中的特殊值：阶码全为 1

当浮点数的**阶码（指数位）全为 1** 时，它不再表示普通的数值，而是用来表示两种特殊值：**无穷大（Infinity）**和**非数（NaN）**。

---

### 无穷大（Infinity）

**条件**：阶码全为 1，且尾数全为 0。

|符号位|含义|
|---|---|
|0|$+\infty$（正无穷）|
|1|$-\infty$（负无穷）|

**产生场景**：

- 溢出：一个超出最大可表示范围的运算结果

**运算规则**：

- $+\infty - (+\infty) = \text{NaN}$（无定义）

---

### 非数（NaN, Not a Number）

**条件**：阶码全为 1，且尾数**不全为 0**。

NaN 用来表示**无意义或未定义的运算结果**。

**产生场景**：

- $\sqrt{-1}$（负数开方）
- 对负数取对数

**NaN 的分类**：

|类型|尾数最高位|用途|
|---|---|---|
|**静默 NaN（qNaN）**|1|运算结果无意义，静默传播，不触发异常|
|**信号 NaN（sNaN）**|0|用于调试，触发无效运算异常|

例如在单精度中：

- `0 11111111 10000000000000000000000` → qNaN
- `0 11111111 00000000000000000000001` → sNaN

**NaN 的传播特性**：

- 任何涉及 NaN 的运算，结果仍然是 NaN
- NaN 与任何值（包括自身）的比较都返回"假"
    - `NaN == NaN` → **false**（这是 NaN 最著名的特性）
    - 这也是为什么检测 NaN 要用 `isNaN(x)` 而不是 `x == NaN`

---

### 完整的 IEEE 754 单精度（32位）分类总览

```
阶码 E 的值          尾数 M          表示的值
─────────────────────────────────────────────────
E = 0（全0）         M = 0          ±0（零）
E = 0（全0）         M ≠ 0          非规格化数（Subnormal）
E = 1~254            任意            规格化数（Normalized）
E = 255（全1）       M = 0          ±∞（无穷大）
E = 255（全1）       M ≠ 0          NaN（非数）
```

---

### 一句话总结

> **阶码全 0** 负责"零附近的小数"（零 + 非规格化数），**阶码全 1** 负责"特殊状态"（无穷大 + NaN），**中间的阶码**才是正常的规格化数。三种区间各司其职，共同构成了完整的浮点数体系。
